# BioSecure Farm

BioSecure Farm is a pig and poultry farm intelligence platform for monitoring animal health, biosecurity, disease alerts, farm locations, veterinary services, and government compliance.

## Endpoints

### Frontend

```text
http://127.0.0.1:5173/
```

### Backend API

```text
http://localhost:5000/api
```

Health check:

```text
http://localhost:5000/api/health
```

### MongoDB

```text
mongodb://127.0.0.1:27017/biosecure_db
```
